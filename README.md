# АГРО-ТЕХ — восемь концепций сайта

Галерея предварительных вариантов редизайна с просмотром на компьютере и телефоне.

Откройте `index.html` и выберите один из восьми вариантов. Каждый макет можно также открыть отдельно: `variant-1.html` — `variant-8.html`.

Формы работают в демонстрационном режиме и не отправляют данные. Рендеры созданы по фотографиям продукции; точная геометрия требует согласования с производителем. В карточках и разделе работ использованы фотографии с сайта agro-teh.su.
